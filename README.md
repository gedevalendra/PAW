## Deskripsi Proyek

Formulir Registrasi adalah proyek web sederhana yang dibuat menggunakan HTML, CSS, dan JavaScript. Proyek ini menyediakan antarmuka pendaftaran yang memungkinkan pengguna mengisi nama lengkap, kata sandi, dan Nomor Induk Mahasiswa (NIM), serta menyetujui syarat dan ketentuan sebelum mengirimkan formulir.

Proyek ini terdiri dari halaman formulir registrasi dan halaman detail pendaftaran dengan desain minimalis, perpaduan warna putih dan biru, serta tata letak yang terstruktur.

## Fitur

- **Formulir Registrasi**  
  Menyediakan input untuk nama lengkap, kata sandi, dan NIM.

- **Validasi Formulir**  
  Menggunakan atribut `required` untuk memastikan kolom wajib diisi dan persetujuan syarat dan ketentuan dicentang sebelum formulir dikirim.

- **Tampilkan dan Sembunyikan Kata Sandi**  
  Memungkinkan pengguna mengubah visibilitas kata sandi melalui tombol pada kolom kata sandi.

- **Halaman Detail Pendaftaran**  
  Menampilkan tabel yang berisi nomor, nama lengkap, kata sandi, NIM, dan aksi untuk mengedit data.

- **Desain Antarmuka**  
  Menggunakan CSS untuk mengatur tata letak, warna, tipografi, sudut elemen, bayangan, dan efek interaksi pada tombol.

## Teknologi yang Digunakan

- **HTML5** — Membuat struktur halaman dan elemen formulir.
- **CSS3** — Mengatur tampilan dan tata letak antarmuka.
- **JavaScript** — Mengatur fungsi tampil dan sembunyi kata sandi.
- **Boxicons** — Menyediakan ikon yang digunakan pada elemen antarmuka.

## Struktur Proyek

```text
proyek-registrasi/
├── index.html
├── detail.html
├── style.css
└── README.md
```

Penjelasan file:

- `index.html` — Halaman utama yang berisi formulir registrasi.
- `detail.html` — Halaman detail pendaftaran yang menampilkan data dalam bentuk tabel.
- `style.css` — File stylesheet yang mengatur tampilan halaman registrasi dan halaman detail.
- `README.md` — Dokumentasi proyek.

## Cara Menjalankan Proyek

1. Unduh atau salin seluruh file proyek ke dalam satu folder.
2. Pastikan `index.html`, `detail.html`, dan `style.css` berada dalam folder yang sama.
3. Buka file `index.html` menggunakan browser seperti Google Chrome, Mozilla Firefox, atau Microsoft Edge.
4. Isi nama lengkap, kata sandi, dan NIM.
5. Centang persetujuan syarat dan ketentuan.
6. Tekan tombol **Daftar** untuk mengirimkan formulir.
